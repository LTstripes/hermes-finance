# Hermes Finance 1.10.5

## Доходность и источники

- Инструмент может показывать результат в рублях и процент за свой наиболее
  ранний подтверждённый период, даже когда история счёта с момента открытия
  недоступна. Обзор, карточка и AI сохраняют фактические границы этого периода.
- Отсутствие промежуточной оценки не скрывает результат внешнего периода с
  подтверждёнными оценками и полными операциями. Неизвестные начальные оценки,
  движения и противоречивые сведения остаются ограничениями.
- Общесчётные расходы не приписываются отдельной бумаге без основания.
  Когда неизвестно только их распределение, отдельно показывается результат
  «Без нераспределённых расходов счёта»; полный результат не выдаётся за точный.
- Связи РЕПО проверяются по исходной идентичности и встречным плечам.
  Неоднозначные связи и неподдержанная экономика РЕПО не превращаются в доходность.
- Сохранённые решения не переписываются автоматически. Затронутое подтверждение
  с изменившимися зависимостями требует проверки; неизменённые основания
  используются только после проверки совместимости.
- Диагностика Т-Инвест содержит метод, период, статус и счётчики событий без
  токенов, персональных данных и сырых ответов. Ошибка HTTP не считается
  успешным ответом без объявленных выплат.

## Месяц, вклады и интерфейс

- Расходы и план сведены в общий рабочий раздел. Вклады редактируются вместе;
  частичное сохранение и потерянный ответ сохраняют неподтверждённые строки
  для проверки, а итоги ждут подтверждающего перечитывания.
- В «Доходе и планах» оценка процентов по вкладам относится к выбранному периоду
  и показана отдельно от датированных выплат. Поступление в том же периоде
  не складывается повторно с оценкой; дата выплаты не выдумывается.
- Закрытие месяца пропускает один повторный полный запрос. Сервер повторно
  проверяет ограничения перед записью и сохраняет отдельное перечитывание
  результата. Сокращение запросов не подтверждает устранение реальной задержки.
- Список инструментов сначала показывает пять строк с раскрытием остальных.
  Неподтверждённые нули в отчётах заменены на «—», частичные суммы объясняются
  через «Подробнее», суммы в распределении капитала не разрываются внутри числа.

Новых миграций базы в этом пакете нет. Обновление не выполняет финансовые
подтверждения, применение данных или открытие закрытых месяцев автоматически.

По явному решению владельца выпуск выполняется без дополнительной UAT на свежей
копии реальных данных. Новый экран X5 на рабочей истории и фактическое время
закрытия месяца на ней не проверены; успешные кодовые и синтетические проверки
не выдаются за такую проверку.
