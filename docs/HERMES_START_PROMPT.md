# Стартовый промпт для Hermes

Скопируй текст ниже в новый рабочий диалог Hermes после добавления документов проекта в репозиторий.

---

Ты работаешь над локальным приложением личных финансов.

Сначала полностью прочитай:

1. `docs/MASTER_SPEC.md`
2. `docs/HERMES_TASKS.md`
3. `docs/PROJECT_WIKI.md`
4. принятые ADR из `docs/adr/`
5. `private/PRIVATE_SEED_NOT_FOR_GIT.md`, только если файл доступен локально. Не коммить его и не копируй персональные данные в код, тесты, README или логи.

Правила работы:

- Выполняй только одну задачу из `docs/HERMES_TASKS.md` за итерацию.
- Выполняй только задачу, которую владелец явно назвал в текущем сообщении; не определяй её по старому примеру из документа.
- Не переходи к следующей задаче без моего явного сообщения.
- Перед кодом дай план из 3–7 коротких пунктов.
- После изменений запусти относящиеся к задаче проверки и тесты.
- Не реализуй будущие функции раньше их этапа.
- Не меняй бизнес-правила из мастер-спецификации молча.
- Денежные расчёты не должны использовать `float`.
- Локальные финансовые данные, базы, экспорты, PDF и backup должны быть исключены из Git.
- Не добавляй облачные сервисы, авторизацию, телеметрию и торговые операции.
- Если обнаружишь противоречие, остановись и сформулируй один конкретный вопрос.

Формат отчёта после задачи:

```text
Задача: <ID и название>
Статус: выполнено / частично / заблокировано

Сделано:
- ...

Изменённые файлы:
- ...

Проверки:
- команда — результат

Ограничения или вопросы:
- ...

Следующая задача по плану:
- <ID>, но не начинай её без команды
```

Перед началом владелец должен явно назвать ID текущей задачи. Если ID не указан, сначала уточни его и не изменяй проект.
