## 0. Назначение

`0.6.0` добавляет два узких owner-controlled пути Alfa поверх локальной месячной модели Hermes:

1. текущий snapshot из Alfa PRO;
2. импорт принятого стандартизированного депозитарного PDF `Отчет о произведенных выплатах доходов по ценным бумагам`.

Это не generic import брокерского портфеля, банковских транзакций, сделок, комиссий, пополнений или выводов. Релиз — local-only, single-user, Windows-first. Нет cloud/auth/telemetry, background refresh, browser → Alfa WebSocket или trading/order/signing API.

### Alfa PRO snapshot

- только по явной кнопке владельца;
- только локальный Alfa PRO loopback;
- явное transient-сопоставление счетов/инструментов; persistent provider mapping не сохраняется;
- provider Price / UchPrice / NKD / P&L — evidence для сравнения, не молчаливая authoritative запись;
- применяются только явно выбранные строки и явно выбранные поля;
- CLOSED month остаётся защищённым и не reopen-ится автоматически;
- trading нет.

### Alfa depository income statement import

- только принятое семейство стандартизированного Alfa income-payment PDF;
- владелец явно выбирает локальный PDF;
- только text layer, без OCR;
- Inspect → transient mapping → Prepare → explicit selected Apply;
- тот же PDF идемпотентен и duplicate-protected;
- manual candidates требуют явного `create_separate` или `link_existing`;
- CLOSED/missing-month операции падают атомарно;
- raw PDF, полный extracted text, original path/filename, beneficiary private data и private provider payload не persist/log;
- account / instrument / month автоматически не создаются.

### Неподвижные инварианты

- runtime слушает только loopback; canonical production address — `127.0.0.1:8000`;
- сеть к провайдеру только после явного действия владельца;
- frontend не является financial source of truth;
- closed month immutable до explicit reopen;
- `Decimal` / integer kopecks + `ROUND_HALF_UP`;
- private DB/seed/exports/backups/tokens/owner payloads не попадают в Git, CI или logs.

## Known limitations

- single local user; no auth/cloud/VPS/HTTPS;
- Alfa PRO only after an explicit owner action against the local terminal; no background refresh;
- statement import is the accepted Alfa income-payment PDF family only; no OCR; no generic brokerage/bank import;
- provider amounts may remain approximate;
- no automatic realized-flow creation from snapshot refresh;
- time-weighted/money-weighted return with dated external flows remains future work;
- the app is not an accounting, tax or trading system.
