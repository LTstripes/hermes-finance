## Operating boundary

Publication uses the unchanged [guarded #124 workflow](../RELEASE_AUTOMATION.md). It never advances a runtime checkout or database. Local updates use the separate backup-first `scripts/update-stable.ps1` from a trusted control checkout; Prepare/Validate and explicit `scripts/start-local.ps1` remain distinct. [Owner runtime operations](../OWNER_RUNTIME_OPERATIONS.md).

Do not use `git pull` in Stable, copy Preview over production, create a blank replacement DB, or attach a development workspace to Owner data. `/v1` shares the backend/database and is not a database rollback. Machine paths, private exports, tokens and databases stay out of tracked files.

Not included in v1.1.0: v1 retirement #573, launcher removal #629, new demo stand #630, class-return implementation #535/#540 or dashboard composer #389. No later work is launched by this release record.
