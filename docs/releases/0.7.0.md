## Accepted product surface

The 0.7.0 tree includes the following already integrated and documented surface:

- **AI Analysis Bundle:** explicit owner-downloadable, schema-valid read-only JSON; no LLM/cloud call, persistence or formula duplication.
- **Monthly Close Cockpit:** server-derived blockers, advisory warnings and context for close readiness; advisory warnings do not silently become hard blockers.
- **Cash-flow Ladder / upcoming treasury events:** dated upcoming events with explicit income versus capital-return context; redemption principal is not passive income.
- **Risk & Allocation:** selected-month persisted RUB valuation with explicit asset-class/account/top-position allocation and payout/redemption concentration; metadata gaps remain unavailable states.
- **Freshness & Provenance Center:** persisted source/freshness clocks and reason codes; no universal score and no background refresh.
- **Reconciliation Center:** explicit read-only snapshot preview, normalized row states and compatibility diagnostics; provider Price/UchPrice/NKD/P&L remain comparison-only.
- **Tax/IIS Planner current-state v1:** current-state tax/IIS workflow is included; projection expansion is deferred.
- **Deterministic Insights backend v1:** read-only persisted-evidence rules; no claim of full UI or AI Analysis Bundle integration.
- **XIRR:** whole-portfolio annualized result only when the persisted evidence yields a valid unambiguous root; invalid, non-convergent or ambiguous roots are unavailable.
- **Exact TWRR:** whole-portfolio nonannualized return using exact persisted opening/closing valuations and observed pre/post valuation boundaries around flows. No interpolation; missing boundaries, gaps or unknown same-day order fail closed.
- **Windows Stable/Preview launcher:** guarded runtime profiles with owner Start/Stop controls; launcher never changes Git branches/state and does not copy Preview into Stable.
- **Alfa compatibility and identity:** compatibility diagnostics, persistent owner-confirmed account/instrument mapping registry and owner-approved baseline quantity apply with provenance.
- **Row-scoped selective apply:** unrelated unresolved/conflicting rows do not block a safe selected subset; selected unsafe or stale rows fail closed.
- **UI and verification:** visual-audit polish, semantic test-taxonomy/verification work and backend CI timeout of 15 minutes.
