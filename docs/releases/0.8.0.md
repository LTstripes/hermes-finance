## Scope

0.8.0 is the owner-workflow release. It integrates the Monthly Close Wizard end-to-end, owner-facing Alfa/reconciliation wording and discoverability, safe duplicate/inactive instrument cleanup, explicit portfolio review handoff packages for ChatGPT/LLM analysis, and the guarded Windows launcher/package verification work already described in `docs/release-notes-0.8.0.md`.

## Preserved boundaries

- local single-user Windows-first runtime;
- loopback only at `127.0.0.1:8000`;
- no cloud/auth/telemetry;
- network/provider/file actions only after explicit owner action;
- closed month immutable until explicit reopen;
- unknown/unavailable evidence is never silently treated as financial zero;
- no automatic upload or LLM call from the portfolio review package.
