# Hermes Finance 1.15.0

## Капитал

- Рыночное изменение брокерского счёта и ИИС в мосте капитала берётся из выписок: рост по выписке минус выплаты, уже учтённые в потоке месяца. Разница между оценкой капитала и выписками на границах месяца показана отдельной строкой «Разница оценки капитала и выписок», а отрицательный остаток подписан как ожидаемое место мелких незаписанных трат (#1156).

## Доходность

- Частичное погашение номинала облигации, которое нельзя привязать к выпуску, больше не превращается в ложный убыток: результат облигаций счёта становится неизвестным. Если в строке есть регистрационный номер известного выпуска, неполнота касается только этого выпуска. Семантика v20 (#1160).
- Результат ИИС за месяц учитывает купоны, дивиденды и реализованный результат только по конец этого месяца, поэтому цифра закрытого месяца больше не меняется задним числом (#1160).
- «Доходность по счёту и периоду» считается за секунды вместо минут; результат не изменился (#1162).
- Обзор «Доходности» — таблица бумаг с колонками «Результат», «На вложенное», «Годовых», «Купоны и дивиденды»; одна оговорка о неполном итоге; купоны, дивиденды и проценты по вкладам отдельными плитками; компактная страница инструмента; вкладки «Обзор» и «По месяцам»; при загрузке — скелеты и прежние данные (#1164).

## Месяц

- Экраны больше не перезагружают данные при переходах и возврате в окно; данные обновляются после изменений и по кнопке «Обновить». Проверка «Закрыть месяц» стала примерно втрое быстрее, а сообщения — короче и без повторов (#1157).
- «Закрыть месяц»: сверху карточка статуса с одним главным действием, цифры месяца с изменением, замечания с кнопкой «Открыть шаг»; у закрытого месяца замечания свёрнуты и нейтральны (#1159).
- Шаги месяца в новом стиле: у закрытого месяца нет неактивных кнопок и пустых форм, проценты в русском формате, расходы и выплаты сгруппированы, связка счёта и долга объяснена один раз (#1161).
- «Позиции»: отдельная таблица на каждый счёт, доля в портфеле, ссылки на страницу бумаги; у счетов из выписок нет пустых колонок (#1158, #1163).
- Единые форматы чисел и подписи статуса месяца («Закрыт»), шапка «Расходов» в черновике показывает сумму, шапка «Выплат» — «Купоны и дивиденды» (#1163).

## Обслуживание

- В статусе записаны публикация и установка 1.14.0 (вместо #1155).

Новых миграций базы данных по сравнению с 1.14.0 нет. Выпуск не выполняет финансовые Apply/Close, импорт или исправление данных.

Изменения расчёта проверены только чтением на установленной базе: строки доходности по инструментам не изменились, результат ИИС за прошлый месяц уменьшился на потоки последующих месяцев, ответы «Доходности по счёту» до и после ускорения совпали побайтно. Это не заменяет подробный числовой UAT установленного 1.15.0.
