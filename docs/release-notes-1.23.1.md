# Finance 1.23.1

## Доходность облигаций

При быстром выборе другого счёта и периода таблица облигаций остаётся на выбранном счёте. Выбор сохраняется при обновлении страницы и при возврате назад.

## Обновление Stable

Перед остановкой приложения штатный режим `-DryRun` проверяет команды, которые понадобятся при запуске в Windows PowerShell. Если дочерний процесс не может проверить SHA256 или готовность сервера, причину можно увидеть, пока текущая версия ещё работает.

## Проверки проекта

Браузерные проверки разделены на три независимо перезапускаемые группы. Для расходов добавлены изолированные сеансы с трассировкой и ноутбучные проверки годового платежа и подушки при неполных данных. Публикация требует полного CI и визуальной проверки для точного коммита в main.

Версия использует схему базы данных 0072. [Изменения выпуска](https://github.com/LTstripes/hermes-finance/pull/1252)
