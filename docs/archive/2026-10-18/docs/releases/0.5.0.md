## 0. Назначение

`0.5.0` добавляет явный owner-controlled календарь будущих инвестиционных выплат поверх локально хранимых позиций Hermes.

T-Invest остаётся read-only источником reference/payout-данных. Позиции остаются локальными данными Hermes: брокерский портфель, счета и операции не импортируются. Релиз — local-only, single-user, Windows-first. Нет cloud/auth/telemetry, background refresh или trading API.

### Принятая семантика, которую 0.5 не пересматривает

- lifecycle: Fetch → Normalize → Preview → owner selection → Apply;
- количество берётся из локального `PositionSnapshot`;
- успешный apply замораживает quantity/total и пишет append-only provenance/revisions;
- `preview_changed` защищает consistency;
- ручные `expected_cash_flows` не перезаписываются и не удаляются apply;
- неразрешённый дубль = только manual; явные решения `keep_both` / `count_manual` / `count_provider`;
- купон провайдера может кормить C04 через merged read model;
- дивиденд провайдера виден в календаре и **не** заменяет/дополняет исторический C04 dividend component;
- погашение — денежный поток, никогда не пассивный доход;
- дата события не создаёт realized investment cash flow;
- нет startup/background provider network.

### Неподвижные инварианты

- runtime слушает только loopback; canonical production address — `127.0.0.1:8000`;
- внешний provider read-only;
- network access только после явного действия владельца;
- frontend не является financial source of truth;
- closed month immutable до explicit reopen;
- `Decimal` / integer kopecks + `ROUND_HALF_UP`;
- private DB/seed/exports/backups/tokens/owner payloads не попадают в Git, CI или logs.

# R05-12. Owner-smoke UX / safe T-Invest mapping blockers — historical

**Priority:** P0
**Status:** DONE / RELEASED (historical)
**Baseline at implementation:** `e59113b0e90f436938c8516cde63fe8f98f09a4a`
**Worker branch:** `r05-12-grok`

Owner smoke of the 0.5.0 candidate found three blockers. This task did not change accepted financial, payout, persistence or provider-identity semantics. The fixes are part of the released 0.5.0 tree.

1. Safe T-Invest candidate disambiguation: discovery projection shows name, ticker, `class_code`, venue and API-trade availability when the provider already returned them. Canonical identity remains `instrument_uid`. No auto-select on ISIN match and no invented tie-break.
2. Mapping dialog scrolling: long candidate lists scroll inside the modal; the background page does not.
3. Truthful payout-preview message: missing accepted T-Invest mapping uses `payout_mapping_required` instead of a generic validation phrase.

Local verification on that candidate: backend `948 passed`; frontend Vitest `242 passed / 41 files`; Ruff check/format pass; Biome lint pass; `tsc -b && vite build` pass; `git diff --check` pass; `privacy_check.py` PASS (503 tracked). Local Windows production smoke was not rerun in that task because `127.0.0.1:8000` was already occupied by the owner runtime.

These blockers were integrated before publication. They are not an open candidate.
