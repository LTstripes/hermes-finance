# Hermes Finance 1.12.0

## Интерфейс

- Этапы 3–5 редизайна «Ясный лист» (#1079, #1117, #1116, #1118): обновлены «Мои финансы», «Доход и планы», «Капитал», обзор доходности и карточка инструмента. Частичные суммы сохраняют явные пометки; равенство в разложении результата показывается только для полных согласованных значений.
- Предупреждения о неполном капитале называют счета без снимков, в том числе за предыдущий месяц (#1125).

## Доходность

- Покупки в одну секунду дают результат, когда порядок исполнений не может его изменить. Историческая пара РЕПО больше не блокирует FIFO, если закрытие и порядок расчётов доказаны; неоднозначные случаи остаются без результата (#1120).
- Проданная позиция получает полный результат, когда сохранённые сделки доказывают нулевой остаток и бумага отсутствует в последней выписке. Неполные сделки, выплаты, погашения и оценки по-прежнему ограничивают результат. Семантика расчёта обновлена до v13 с совместимостью сохранённых подтверждений v12 (#1133).
- Повторные чтения инструментов, источников и выплат переиспользуются внутри одного защищённого снимка запроса. Долгоживущий кеш и изменения финансовых формул не вводятся (#1126).

## Проверки и обслуживание

- Подготовка версии синхронизирует манифесты и lock-файлы; запрос публикации проверяет точный main и его успешный CI перед единственным комментарием в Release Control (#1121).
- Добавлен пошаговый backup-first updater Stable с явным путём базы, новой папкой копии и отдельным запуском приложения (#1122).
- Устранены причины ложных падений браузерных проверок без ослабления утверждений; тесты месяца переведены на текущий рабочий маршрут с сохранением уникальных проверок гонок и восстановления (#1123, #1127).
- Добавлена локальная проверка покрытия доходности на временной копии базы, открываемой только для чтения. CI использует исключительно синтетические данные (#1124).

Новых миграций базы данных по сравнению с 1.11.0 нет. Выпуск не выполняет финансовые Apply/Close, импорт или исправление данных.

В #1124 и #1133 зафиксированы локальные проверки только чтением на копии реальных данных. Они не заменяют подробный числовой UAT установленного 1.12.0: при подготовке выпуска он не проводился и здесь не заявляется.
