# Hermes Finance 1.10.2

## Скорость чтения

- Объяснение изменения капитала использует результат нужного месяца без расчёта
  исторического XIRR. Повторное использование ограничено одним согласованным снимком БД.
- Главная и закрытие месяца пропускают объяснение, которое они не показывают.
  Обычные API сравнения и сводки сохраняют полный ответ по умолчанию.
- Сохранённый прогноз выплат появляется до завершения дополнительных проверок
  сопоставлений и согласованности. Поздние ответы сохраняют привязку к своему контексту.

## Подтверждения и инструменты

- Добавлена узкая совместимость сохранённых инвестиционных подтверждений 1.9.4:
  заново проверяются все текущие зависимости, исходники и физическая БД.
  Сохранённые доказательства и закрытые месяцы остаются неизменными.
- Строки инструментов показывают компактные результаты каждого счёта;
  даты, причины и допущения раскрываются по запросу.
- Ограниченный месячный reader сохраняет порядок обработки proofs полного reader
  при нескольких алиасах одного брокерского счёта.

Неподтверждённые денежные операции и секционные доказательства по-прежнему оставляют
результат недоступным. Полная AI-выгрузка может занимать длительное время.
Миграций схемы и изменений финансовых записей в этом выпуске нет.
