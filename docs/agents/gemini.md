# Gemini adapter

This file is a Gemini client adapter. It does not replace [`AGENTS.md`](../../AGENTS.md).

No project-wide Gemini orchestration or model-routing scheme is required yet.

Gemini follows the common repository constitution whether acting as:

- a read-only reviewer;
- a researcher;
- an implementation worker.

Machine-specific CLI or project settings remain local. Do not write them into the repository.
