# Finance 1.24.0

## Накопительные счета Альфы

В черновике закрытия месяца откройте «Активы» → «Депозиты» → «Заполнить депозиты из выписки». После загрузки CSV выберите счёт и сравните текущий и предложенный остатки, полученные проценты и ставку. Каждое изменение подтверждается отдельно по счёту.

Для расчёта остатка нужны все движения за календарный месяц и остаток на последний день предыдущего месяца. Если исходного остатка нет, в существующем снимке можно подтвердить проценты, которые удалось установить по выписке. При повторной загрузке сохраняется привязка счёта.

## Сверка выплат по PDF

При подготовке отчёта о выплатах и после применения выбранных строк видны число подтверждённых совпадений и выплаты, которые требуют внимания. Для каждого расхождения показана причина. Будущие выплаты и строки вне подтверждённого покрытия вынесены отдельно. Ранее принятые решения о соответствии сохраняются при повторной загрузке PDF.

## Документация и установка

В начале книги финансовых контрактов появился указатель по шести задачам, включая закрытие месяца, сверку выплат и расчёт подушки. Версия приложения использует схему базы 0073 с таблицей привязок накопительных счетов.
