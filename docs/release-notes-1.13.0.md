# Finance 1.13.0

## Доходность

- Купон не привязывается к акции эмитента по названию: точный ISIN или регистрационный номер выпуска важнее совпадения имени. Неоднозначные выплаты остаются непривязанными. Дивиденды с расширенным описанием выпуска привязываются по явной связи с акцией. Полное погашение облигации восстанавливается только при подтверждённом аннулировании выпуска и точном совпадении количества, номинала и суммы. Семантика v14 (#1140).
- Продажа облигации с НКД отдельной денежной строкой сверяется точно: тело плюс НКД должны совпасть с суммой сделки до копейки. Если не совпадают, продажа остаётся без результата. Семантика v15 (#1141).
- У каждой позиции есть простой процент на вложенное и годовая доходность XIRR. XIRR показывается, только если средний срок владения, взвешенный по вложениям, не меньше года; иначе значение пустое с причиной. Modified Dietz позиции сохранён в API, но не служит для сравнения позиций. Семантика v16 (#1142, решение владельца в #1016).

## Интерфейс

- Список бумаг на экране «Доходность» и карточка бумаги показывают простой процент на вложенное и, когда он есть, годовой XIRR вместо Modified Dietz за период. При коротком владении один раз поясняется, почему годовой процент не показан (#1144).

## AI-выгрузка

- Формат 3.2.0 (#1143): названия бумаг и счетов, закрытые позиции и золото, датированные фактические выплаты по бумаге, сводка по ISIN, подписи у каждого процента (метод, база, даты, годовой или нет), простой процент и XIRR позиции, явная пометка неизвестной себестоимости. Разделение на реализованный и нереализованный результат указано только для подтверждённо закрытых позиций, в остальных случаях оно неизвестно. Сохранённые файлы 2.0.0 и 3.1.0 по-прежнему читаются.
- Старые форматы выгрузки, которые не использовал интерфейс, удалены (#1139).

## Проверки и обслуживание

- Пошаговое обновление Stable больше не прерывается на сообщениях git в stderr под Windows PowerShell 5.1 (#1138).
- Удалены неиспользуемый код, дублирующиеся тесты и шаги CI, а также недостижимые ветки `workspace=false` (#1136, #1137).

Новых миграций базы данных по сравнению с 1.12.0 нет. Выпуск не выполняет финансовые Apply/Close, импорт или исправление данных.

Изменения расчёта проверены только чтением на копии реальных данных: полных результатов позиций стало 27 вместо 24, покупок с результатом 239 вместо 236, открытые позиции не ухудшились. Это не заменяет подробный числовой UAT установленного 1.13.0: при подготовке выпуска он не проводился и здесь не заявляется.
