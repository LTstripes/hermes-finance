# Finance 1.20.0

Выпуск после аудита 15.11.2026: доводка плана целей, единые названия бумаг, стабильность ввода и обновление зависимостей.

## Цели

- В «Плане достижения» необходимый взнос к сроку виден и тогда, когда поле взноса пустое или цель при введённом взносе не достигается (#1214).
- Неверная доходность в плане всегда отклоняется как ошибка ввода, независимо от наличия данных за месяц (#1214).

## Названия бумаг

- Короткое название бумаги теперь приходит и в свежести котировок, в доходах по источникам и в доходности по брокерской выписке; на экране свежести показывается короткое название (#1213).

## Ввод

- В редактировании долга и недвижимости курсор больше не перескакивает в поле названия, если вы уже начали вводить сумму в другом поле (#1216).

## Обслуживание

- Чтение PDF-выписок использует pypdf 6.21.4 с исправлением чрезмерного расхода памяти на повреждённых файлах; обновлены инструменты разработки фронтенда (#1218).
- Подготовка версии меняет только поля самого проекта; заголовок будущих релизов — «Finance X.Y.Z» (#1215).
- Нестабильные тесты исправлены по причине, сценарии плана целей и Returns API включены в CI; удалён неиспользуемый код, видимые сообщения скриптов используют имя Finance, уточнены формулировки документов (#1216, #1217).

Новых миграций базы данных по сравнению с 1.19.0 нет. Финансовые расчёты не менялись. Выпуск не выполняет финансовые Apply/Close, импорт или исправление данных.
