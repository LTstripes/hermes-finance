# Finance 1.22.0

В меню появился раздел «Траты». Раз в месяц можно загрузить CSV-выписку Альфа-Банка и один файл Markdown с ручными тратами, например наличными и по карте Сбера.

## Загрузка

- Раздел «Траты» предлагает скачать шаблон ручного файла. Перед применением можно проверить покупки, возвраты, возможные дубли, переводы и операции без категории. Неразобранные операции можно оставить на потом.
- При повторной загрузке выписки данные заменяются в пределах периода нового файла по каждому счёту. Удаление ранее загруженных операций требует подтверждения. Однозначно сопоставленные решения сохраняются.
- Дневник хранится отдельно от месячных фактов. Траты можно загрузить и после закрытия месяца. Связь операции с расходом из отчёта месяца позволяет учесть их один раз.

## Аналитика

- На экране «Траты» доступны итог месяца, сравнение с тремя полными месяцами, история за 12 месяцев, разбивка по категориям, крупные покупки, накопительный график по дням и фильтры операций.
- Повторяющиеся решения можно сохранить в правилах по продавцу или категории банка.
- Предпросмотр показывает суммы до и после по наборам. Общая разница, диапазон замены по каждому набору и исходный текст ошибочной строки пока недоступны. Доли категорий округляются до десятых.

Обновление включает миграции `0069_spending_diary` и `0070_spending_screen`. Исходные изменения описаны в [#1229](https://github.com/LTstripes/hermes-finance/pull/1229) и [#1230](https://github.com/LTstripes/hermes-finance/pull/1230).
