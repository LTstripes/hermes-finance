## Variant: Airy Editorial

### Design stance
Revolut-product air: wide sidebar, stadium-scale numbers, pill everything, teal accent, flat surfaces.

### Key choices
- Layout: 280px sidebar, 2×2 KPI cards, generous 56px page padding
- Typography: Inter 15px body, ~2–3.4rem headlines, less mono on big figures
- Color: near-black `#191c1f` sidebar, pure white content, teal `#00a87e`
- Interaction: 48px pill buttons, zero hard shadows, centered toast

### Trade-offs
- Strong at: delight, marketing-grade calm, big number storytelling
- Weak at: table density, form packing, feels sparse once months list grows

### Best for
If dashboard is mostly KPI storytelling and sparse navigation — less ideal for dense month editor (E04+).
