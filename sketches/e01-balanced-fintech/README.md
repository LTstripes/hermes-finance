## Variant: Balanced Fintech

### Design stance
Evolved HF seed × Stripe precision: forest dark sidebar, soft light canvas, one green accent, calm cards.

### Key choices
- Layout: 248px sidebar (current shell), 1100px content, 4 KPI + 2-col work area
- Typography: Inter ~14px, display headings with tight tracking, mono money
- Color: sidebar `#111814`, accent `#27734c`, bg `#f3f4ef`, soft green-tinted elevation
- Interaction: 40–42px controls, 150ms ease-out, press scale 0.97

### Trade-offs
- Strong at: continuity with existing skeleton, MASTER_SPEC “clean modern dashboard”, trust/fintech calm
- Weak at: less “wow” than airy; less density than pure tool mode

### Best for
Default Hermes Finance MVP — readable monthly workflow without terminal vibes.
