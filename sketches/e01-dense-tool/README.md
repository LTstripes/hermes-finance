## Variant: Dense Tool

### Design stance
Linear-precision hybrid: compact dark sidebar, tight 8px rhythm, indigo accent, mono tabular money.

### Key choices
- Layout: 220px sidebar, sticky 48px topbar, dense 4-col KPI strip
- Typography: Inter 13px UI + JetBrains Mono for money (`tnum`)
- Color: near-black sidebar `#0f1011`, accent indigo `#5e6ad2`, cool light content `#f7f8f8`
- Interaction: 32px controls, 140ms ease-out, inset accent on active nav

### Trade-offs
- Strong at: scanning many numbers/tables, power-user density, future multi-page nav
- Weak at: first-impression warmth, large empty states feel cramped

### Best for
Daily personal finance ops with lots of months/rows — tool first, brochure never.
