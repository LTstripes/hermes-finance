# Hermes Finance

Local single-user Windows personal-finance application: monthly snapshots, actual income, portfolios, source review, planning and exports. Normal runtime is loopback-only; money uses exact backend arithmetic.

The current handbook has five books:

1. [Product and user journeys](docs/MASTER_SPEC.md)
2. [Architecture, financial semantics and contracts](docs/ARCHITECTURE_AND_CONTRACTS.md)
3. [Development, verification and integration](docs/DEVELOPMENT.md)
4. [Operations, release and recovery](docs/OWNER_RUNTIME_OPERATIONS.md)
5. [Current state, limitations and next actions](docs/CURRENT_STATUS.md)

Contributors start with [AGENTS](AGENTS.md) and their assigned issue. [CHANGELOG](CHANGELOG.md) records releases; the [documentation index](docs/README.md) lists the books and supporting collections. [Historical migration map](docs/archive/2026-10-18/MIGRATION_MAP.md) locates retained evidence. Current status is maintained only in CURRENT_STATUS.
