# Native month editor leaf contract

The editor route is `/v2/data/months/:monthId`. `monthId` must be a positive safe integer; the page calls `getMonth(id)` and never selects another month after a 404. The only active `section` values in #558 are `general` (the default) and `note`. Unknown values show an error. The six later editor slices must register their own section IDs when accepted; this frame does not display them as working tabs.

Leaf components receive `MonthEditorContext` from `UiV2MonthEditorPage.tsx`: the exact `month`, `readOnly` derived from its current status, a confirmed `refresh()`, `setDirty(section, value)`, and `returnToClose` when the validated `from`/`monthId`/`step` query names this same month. A leaf must clear its dirty flag on unmount, key its requests and local state to `month.id`, and ignore responses after that identity changes. It must use its own canonical API and read back its write; no shared save transaction exists. `readOnly` prohibits mutations until the user explicitly confirms reopen. Reopen only changes lifecycle through `reopenMonth` and then rereads `getMonth`; it does not close the month again or reset evidence in the frontend.

Internal editor links preserve the validated return query. Navigation with a dirty leaf asks before discarding, including browser Back. Browser reload/close uses the platform's unsaved-changes prompt. The v1 editor route remains available as an explicit escape for sections that have not reached native parity.
